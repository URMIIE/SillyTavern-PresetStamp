# Preset Stamp

SillyTavern 확장. PresetTrackerEnhanced 와 같은 일을 하는 새 확장이에요(코드는 새로 씀). 답(스와이프)마다 **어떤 모델 · 프리셋으로 만들었는지** 그 메시지에 도장처럼 적어 두고, 나중에 볼 수 있게 해 줘요.

## 무엇을 적나

- 모델, 연결 종류(api), 프리셋 이름
- 연결 프로필을 쓰면 프로필 이름
- 텍스트 완성이면 컨텍스트 템플릿 · 지시 템플릿 · 시스템 프롬프트 이름

**생성이 시작될 때** 적어요. 생성 중에 프리셋을 바꿔도 그 답을 만든 설정이 남아요.

## 보는 법

AI 메시지의 **캐릭터 이름을 누르면** 그 답(지금 보이는 스와이프)의 모델 · 프리셋이 알림으로 떠요.

확장 설정의 **Preset Stamp** 칸에서 알림에 보일 정보를 켜고 끌 수 있어요: 모델 · 연결 종류 · 연결 프로필 · 프리셋 · 텍스트 완성 템플릿 · 생성 시작 시각. (기록은 설정과 상관없이 늘 다 해 둬요.)

## 이런 경우도 맞게 남아요

- **잘라서 다시 넣는 QR** (`/cut` 으로 마지막 답을 지우고 `/sendas` 로 다시 넣기): 실리태번은 이렇게 넣은 메시지의 모델을 `slash command` 로 적어요. 새 글 안에 방금 지운 답이 그대로 들어 있으면 원래 답의 모델 · 프리셋을 이어받고, 실리태번 기록(시간에 마우스를 올리면 보이는 모델)도 원래 모델로 고쳐요.
- **`/gen` 으로 만들고 `/sendas` 로 넣는 QR**: `/gen` 이 시작될 때의 모델 · 프리셋을 적어요.
- **스트리밍 중 멈춤**, **도중 오류로 끊긴 답 · 스와이프**도 남은 답에 기록해요. 실패해서 답이 아예 안 생기면(429 등) 아무것도 적지 않고, 다른 답에 잘못 붙지도 않아요.
- 새 스와이프는 앞 스와이프의 기록을 물려받지 않아요(실리태번은 새 스와이프에 앞 스와이프 정보를 넘겨주는데, 이 기록은 떼어 내요).
- 이어 쓰기는 처음 만든 답의 기록을 그대로 둬요.
- 스와이프마다 따로, 분기 채팅에도 그대로 따라가요. 메시지를 지우면 기록도 같이 지워져서 따로 정리할 게 없어요.

## 기록 위치

메시지의 `extra.preset_stamp` (스와이프는 `swipe_info[n].extra.preset_stamp`). 채팅 파일 안에 들어 있어요.

## Preset Tracker 를 쓰던 분

옛 PresetTrackerEnhanced 가 적어 둔 기록(`presetsBySwipeKey`)은 읽기만 해서 그대로 보여 줘요(지우거나 바꾸지 않아요). 두 확장을 같이 켜면 이름을 누를 때 알림이 두 번 뜨니, 옛 확장은 꺼 주세요.

## 알아 둘 점

- 이 확장을 설치하기 전에 만든 답은 프리셋을 알 수 없어요(모델은 실리태번 기록으로 보여 줘요).
- `/gen` 없이 직접 쓴 글을 `/sendas` 로 넣으면 원래대로 `slash command` 예요. 다만 다른 확장이 뒤에서 조용히 생성한 직후(10분 안)라면 그 생성의 모델이 붙을 수 있어요.
- 잘라 넣는 QR 이 정규식 등으로 원래 글을 바꿔 넣으면 짝을 못 찾을 수 있어요.
